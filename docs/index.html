    Minimax

    Tic-Tac-Toe is small enough to solve completely. The AI assigns every finished board a utility: +1 if X won, −1 if O won, 0 for a draw. Then it reasons backwards: on X's turn the value of a position is the max over the moves' values, on O's turn the min — each side assumes the other plays perfectly.

    value(board):
  if terminal(board): return utility(board)
  if player(board) == X: return max(value(result(board, a)) for a in actions(board))
  else:                  return min(value(result(board, a)) for a in actions(board))

    From the empty board the value is 0: with perfect play the game is always a draw. That's why the Hard AI can never lose — and why you can never beat it. The best you can do is draw; every "win" is a draw you failed to reach.

    Depth-adjusted values

    A plain ±1 doesn't distinguish "win now" from "win in five moves". The engine nudges values by the depth (1.09 beats 1.05) so the AI takes the quickest win and postpones a loss as long as possible — giving you the most chances to slip.

    Alpha-beta pruning

    Minimax from the empty board visits 549,945 nodes. Most of that work is wasted: once X has found a move that guarantees a draw, it doesn't need to fully explore an alternative that O can already answer with something worse. Alpha-beta keeps two bounds — α, the best X can already secure; β, the best O can — and abandons any branch that can't change the decision.

    if player == X: alpha = max(alpha, best); if alpha >= beta: stop
else:           beta  = min(beta,  best); if alpha >= beta: stop

    Same answer, 34,202 nodes instead of 549,945 — a 16× cut on the first move, and the ratio grows with the branching factor in bigger games (chess engines would be nowhere without it). Watch the two numbers side by side in the AI thinking panel after every move.

    Difficulty levels

    • Easy plays a random legal move.
    • Medium runs the same search but stops two moves ahead, scoring unfinished positions 0 — so it takes wins and blocks threats, but walks into forks.
    • Hard searches to the end: perfect play.
